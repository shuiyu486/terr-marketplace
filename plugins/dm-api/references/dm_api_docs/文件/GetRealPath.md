# GetRealPath

**分类:** 文件

**签名:** `string GetRealPath(path)`

**描述:** 获取指定文件或目录的真实路径

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| path | str | 路径名,可以是文件路径，也可以是目录. 这里必须是全路径 |

## 返回值

- 真实路径,如果失败,返回空字符串

## 示例

```vbs
TracePrint dm.GetRealPath("c:\11\22\3.txt")
```

## 注意

- 这个功能可以获取到路径中有符号链接之后的，真实路径.
