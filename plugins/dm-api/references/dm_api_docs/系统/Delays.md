# Delays

**分类:** 系统

**签名:** `long Delays(mis_min,mis_max)`

**描述:** 延时指定范围内随机毫秒,过程中不阻塞UI操作. 一般高级语言使用.按键用不到.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| mis_min | int | 最小毫秒数. **必须大于0** |
| mis_max | int | 最大毫秒数. **必须大于0** |

## 返回值

- 0 : 失败
- 1 : 成功

## 示例

```vbs
dm.Delays 200,1000
```

## 注意

- 由于是com组件,调用此函数必须保证调用线程的模型为MTA.否则此函数可能会失效.
