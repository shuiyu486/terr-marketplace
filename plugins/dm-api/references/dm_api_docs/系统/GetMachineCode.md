# GetMachineCode

**分类:** 系统

**签名:** `string GetMachineCode()`

**描述:** 获取本机的机器码.(带网卡). 此机器码用于插件网站后台. 要求调用进程必须有管理员权限. 否则返回空串.

## 参数

*此函数无参数。*

## 返回值

- 字符串表达的机器机器码

## 示例

```vbs
machine_code = dm.GetMachineCode()
```

## 注意

- 此机器码包含的硬件设备有硬盘,显卡,网卡等. 其它不便透露. 重装系统不会改变此值.
- 另要注意,插拔任何USB设备,(U盘，U盾,USB移动硬盘,USB键鼠等),以及安装任何网卡驱动程序,(开启或者关闭无线网卡等)都会导致机器码改变.
