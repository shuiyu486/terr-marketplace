# SetUAC

**分类:** 系统

**签名:** `long SetUAC(enable)`

**描述:** 设置当前系统的UAC(用户账户控制).

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| enable | int | 取值如下 |

## 返回值

- 0 : 操作失败
- 1 : 操作成功

## 示例

```vbs
if dm.SetUAC(0) = 1 then
TracePrint "成功关闭了当前系统UAC设置"
end if
```

## 注意

- 只有WIN7 WIN8 VISTA WIN2008以及以上系统才有UAC设置. 关闭UAC以后，必须重启系统才会生效.
- 如果关闭了UAC，那么默认启动所有应用程序都是管理员权限，就不会再发生绑定失败这样的尴尬情况了.
