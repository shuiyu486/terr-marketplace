# GetNetTimeByIp

**分类:** 系统

**签名:** `string GetNetTimeByIp(ip)`

**描述:** 根据指定时间服务器IP,从网络获取当前北京时间.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| ip | str | IP或者域名,并且支持多个IP或者域名连接 |

## 返回值

- 时间格式. 和now返回一致. 比如"2001-11-01
- 23:14:08"

## 示例

```vbs
t = dm.GetNetTimeByIp("210.72.145.44|ntp.sjtu.edu.cn")
TracePrint "当前北京时间是:"&t
```

## 注意

- 如果程序无法访问时间服务器，那么返回"0000-00-00 00:00:00"
- 时间服务器的IP可以从网上查找NTP服务器.
