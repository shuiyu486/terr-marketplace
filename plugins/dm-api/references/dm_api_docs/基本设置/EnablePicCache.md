# EnablePicCache

**分类:** 基本设置

**签名:** `long EnablePicCache(enable)`

**描述:** 设置是否开启或者关闭插件内部的图片缓存机制. (默认是打开).

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| enable | int |  |

## 返回值

- 0: 失败
- 1: 成功

## 示例

```vbs
dm.EnablePicCache 0
```

## 注意

- 有些时候，系统内存比较吃紧，这时候再打开内部缓存，可能会导致缓存分配在虚拟内存，这样频繁换页，反而导致图色效率下降.这时候就建议关闭图色缓存.
- 所有图色缓存机制都是对本对象的，也就是说，调用图色缓存机制的函数仅仅对本对象生效. 每个对象都有一个图色缓存队列.
