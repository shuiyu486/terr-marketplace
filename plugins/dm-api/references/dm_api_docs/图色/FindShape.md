# FindShape

**分类:** 图色

**签名:** `long FindShape(x1, y1, x2, y2, offset_color,sim, dir,intX,intY)`

**描述:** 查找指定的形状. 形状的描述同按键的抓抓. 具体可以参考按键的抓抓.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| x1 | int | 区域的左上X坐标 |
| y1 | int | 区域的左上Y坐标 |
| x2 | int | 区域的右下X坐标 |
| y2 | int | 区域的右下Y坐标 |
| offset_color | str | 坐标偏移描述 可以支持任意多个点 格式和按键自带的Color插件意义相同 格式为"x1|y1|e1,……xn|yn|en" 比如"1|3|1,-5|-3|0"等任意组合都可以 |
| sim | double | 相似度,取值范围0.1-1.0 |
| dir | int | 查找方向 0: 从左到右,从上到下 1: 从左到右,从下到上 2: 从右到左,从上到下 3: 从右到左, 从下到上 |
| intX | int* | 返回X坐标(坐标为形状(0,0)所在坐标) |
| intY | int* | 返回Y坐标(坐标为形状(0,0)所在坐标) |

## 返回值

- 0:没找到
- 1:找到

## 示例

```vbs
dm_ret = dm.FindShape(0,0,2000,2000,
"1|1|0,1|6|1,0|10|1,9|10|1,7|6|1,7|8|0,8|9|0,2|2|1,3|1|1",1.0,0,x,y)
dm.MoveTo x,y
```
