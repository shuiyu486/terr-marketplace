# GetScreenDataBmp

**分类:** 图色

**签名:** `long GetScreenDataBmp(x1,y1,x2,y2,data,size)`

**描述:** 获取指定区域的图像,用24位位图的数据格式返回,方便二次开发.（或者可以配合SetDisplayInput的mem模式）

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| x1 | int | 区域的左上X坐标 |
| y1 | int | 区域的左上Y坐标 |
| x2 | int | 区域的右下X坐标 |
| y2 | int | 区域的右下Y坐标 |
| data | int* | 返回图片的数据指针 |
| size | int* | 返回图片的数据长度 |

## 返回值

- 0 : 失败
- 1 : 成功

## 示例

```vbs
以下是在E语言中的示例.

.局部变量 data, 整数型

.局部变量 size, 整数型

dm.数值方法 (“GetScreenDataBmp”,
0, 0, 100, 200, data, size)

图片框1.图片 ＝ 指针到字节集 (data, size)

需要注意的是,调用此接口获取的数据指针保存在当前对象中,到下次调用此接口时,内部就会释放.
哪怕是转成字节集,这个地址也还是在此字节集中使用. 如果您要此地址一直有效，那么您需要自己拷贝字节集到自己的字节集中.
```
