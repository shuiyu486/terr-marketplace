# CmpColor

**分类:** 图色

**签名:** `long CmpColor(x,y,color,sim)`

**描述:** 比较指定坐标点(x,y)的颜色

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| x | int | X坐标 |
| y | int | Y坐标 |
| color | str | 颜色字符串,可以支持偏色,多色,例如 "ffffff-202020|000000-000000" 这个表示白色偏色为202020,和黑色偏色为000000.颜色最多支持10种颜色组合. 注意，这里只支持RGB颜色. |
| sim | double | 相似度(0.1-1.0) |

## 返回值

- 0: 颜色匹配
- 1: 颜色不匹配

## 示例

```vbs
dm_ret = dm.CmpColor(200,300,"000000-000000|ff00ff-101010",0.9)
If dm_ret = 0 Then
MessageBox
"相等"
End If
```
