# WaitKey

**分类:** 键鼠

**签名:** `long WaitKey(vk_code,time_out)`

**描述:** 等待指定的按键按下 (前台,不是后台)

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| vk_code | int | 虚拟按键码,当此值为0，表示等待任意按键。 鼠标左键是1,鼠标右键时2,鼠标中键是4. |
| time_out | int | 等待多久,单位毫秒. 如果是0，表示一直等待 |

## 返回值

- 0:超时
- 1:指定的按键按下 (当vk\_code不为0时) 按下的按键码:(当vk\_code为0时)

## 示例

```vbs
dm.WaitKey 66,0
```
