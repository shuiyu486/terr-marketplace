# KeyPressStr

**分类:** 键鼠

**签名:** `long KeyPressStr(key_str,delay)`

**描述:** 根据指定的字符串序列，依次按顺序按下其中的字符.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| key_str | str | **:** 需要按下的字符串序列. 比如"1234","abcd","7389,1462"等. |
| delay | int | 每按下一个按键，需要延时多久. 单位毫秒.这个值越大，按的速度越慢。 |

## 返回值

- 0:失败
- 1:成功

## 示例

```vbs
dm.KeyPressStr "123,456",20
```

## 注意

- 在某些情况下，SendString和SendString2都无法输入文字时，可以考虑用这个来输入.
- 但这个接口只支持标准ASCII可见字符,其它字符一律不支持.(包括中文)
