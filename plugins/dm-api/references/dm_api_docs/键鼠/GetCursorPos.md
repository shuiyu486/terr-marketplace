函数简介:

获取鼠标位置.

函数原型:  
  
long GetCursorPos(x,y)

参数定义:  
  
x 变参指针: 返回X坐标

y 变参指针: 返回Y坐标

返回值:

整形数:  
0 : 失败

1 : 成功

示例:

dm.GetCursorPos x,y  
MessageBox x&","&y

注: 此接口在3.1223版本之后，返回的值的定义修改。  同大多数接口一样,返回的x,y坐标是根据绑定的鼠标参数来决定.  如果绑定了窗口，那么获取的坐标是相对于绑定窗口，否则是屏幕坐标.    
另外，此函数获取的坐标是真实的鼠标坐标，对于某些自绘鼠标位置不一定准确。请自行测试.
