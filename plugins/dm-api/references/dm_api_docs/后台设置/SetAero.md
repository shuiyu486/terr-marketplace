# SetAero

**分类:** 后台设置

**签名:** `long SetAero(enable)`

**描述:** 设置开启或者关闭系统的Aero效果. (仅对WIN7及以上系统有效)

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| enable | int | 0 关闭 |

## 返回值

- 0: 失败
- 1: 成功

## 示例

```vbs
dm.SetAero 0
```

## 注意

- 如果您发现当图色后台为dx2 gdi dx3时，如果有发现目标窗口刷新速度过慢,那可以考虑关闭系统Aero. (当然这仅仅是可能的原因)
