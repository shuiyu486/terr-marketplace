# EnableBind

**分类:** 后台设置

**签名:** `long EnableBind(enable)`

**描述:** 设置是否暂时关闭或者开启后台功能. 默认是开启.  一般用在前台切换，或者脚本暂停和恢复时，可以让用户操作窗口.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| enable | int | 0 全部关闭(图色键鼠都关闭,也就是说图色,键鼠都是前台,但是如果有指定dx.public.active.message时，在窗口前后台切换时，这个属性会失效.) -1 只关闭图色.(也就是说图色是normal前台. 键鼠不变) |

## 返回值

- 0: 失败
- 1: 成功

## 示例

```vbs
// 绑定为后台
dm_ret = dm.BindWindow(hwnd,"dx","dx","dx",101)
// 后台操作
…
// 切换到前台
dm.EnableBind 0
// 前台操作
…
// 再切换回后台
dm.EnableBind 1
```

## 注意

- 注意切换到前台以后,相当于dm\_ret = dm.BindWindow(hwnd,"normal","normal","normal",0),图色键鼠全部是前台.
- 如果你经常有频繁切换后台和前台的操作，推荐使用这个函数.
- 同时要注意,如果有多个对象绑定了同个窗口，其中任何一个对象禁止了后台,那么其他对象后台也同样失效.
