# SetDictPwd

**分类:** 文字识别

**签名:** `long SetDictPwd(pwd)`

**描述:** 设置字库的密码,在SetDict前调用,目前的设计是,所有字库通用一个密码.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| pwd | str | 字库密码 |

## 返回值

- 0:失败
- 1:成功

## 示例

```vbs
dm_ret = dm.SetDictPwd("1234")
```

## 注意

- 如果使用了多字库,所有字库的密码必须一样. 此函数必须在SetDict之前调用,否则会解密失败.
