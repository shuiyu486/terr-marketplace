# SetExactOcr

**分类:** 文字识别

**签名:** `long SetExactOcr(exact_ocr)`

**描述:** 高级用户使用,在使用文字识别功能前，设定是否开启精准识别.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| exact_ocr | int | 0 表示关闭精准识别 |

## 返回值

- 0:失败
- 1:成功

## 示例

```vbs
// 开启精准识别
dm_ret = dm.SetExactOcr(1)
```

## 注意

- 精准识别开启后，行间距和列间距会对识别结果造成较大影响，可以在工具中进行测试.
