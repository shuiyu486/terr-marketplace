# SetDict

**分类:** 文字识别

**签名:** `long SetDict(index,file)`

**描述:** 设置字库文件

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| index | int | 字库的序号,取值为0-99,目前最多支持100个字库 |
| file | str | 字库文件名 |

## 返回值

- 0:失败
- 1:成功

## 示例

```vbs
dm_ret = dm.SetDict(0,"test.txt")
```

## 注意

- 此函数速度很慢，全局初始化时调用一次即可，切换字库用UseDict
