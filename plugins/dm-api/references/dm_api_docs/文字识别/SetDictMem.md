# SetDictMem

**分类:** 文字识别

**签名:** `long SetDictMem(index,addr,size)`

**描述:** 从内存中设置字库.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| index | int | 字库的序号,取值为0-99,目前最多支持100个字库 |
| addr | int | 数据地址 |
| size | int | 字库长度 |

## 返回值

- 0:失败
- 1:成功

## 示例

```vbs
dm_ret = dm.SetDictMem(0,234324,1000)
```

## 注意

- 此函数速度很慢，全局初始化时调用一次即可，切换字库用UseDict
- 另外，此函数不支持加密的内存字库.
