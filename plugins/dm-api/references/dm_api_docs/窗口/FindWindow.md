# FindWindow

**分类:** 窗口

**签名:** `long FindWindow(class,title)`

**描述:** 查找符合类名或者标题名的顶层可见窗口

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| class | str | 窗口类名，如果为空，则匹配所有. 这里的匹配是模糊匹配. |
| title | str | 窗口标题,如果为空，则匹配所有.这里的匹配是模糊匹配. |

## 返回值

- 整形数表示的窗口句柄，没找到返回0

## 示例

```vbs
hwnd = dm.FindWindow("","记事本")
```
