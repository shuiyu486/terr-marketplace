# SendString2

**分类:** 窗口

**签名:** `long SendString2(hwnd,str)`

**描述:** 向指定窗口发送文本数据

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| hwnd | int | 指定的窗口句柄. 如果为0,则对当前激活的窗口发送. |
| str | str | 发送的文本数据 |

## 返回值

- 0: 失败
- 1: 成功

## 示例

```vbs
dm.SendString2 hwnd,"我是来测试的"
```

## 注意

- 此接口为老的SendString，如果新的SendString不能输入，可以尝试此接口.
- 有时候发送中文，可能会大部分机器正常，少部分会乱码。这种情况一般有两个可能
- 系统编码没有设置为GBK
- 目标程序里可能安装了改变当前编码的软件，比如常见的是输入法. （尝试卸载）
