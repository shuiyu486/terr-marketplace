函数简介:

设置窗口的状态

函数原型:  
  
long SetWindowState(hwnd,flag)

参数定义:  
  
hwnd 整形数: 指定的窗口句柄  
  
flag 整形数: 取值定义如下

0 : 关闭指定窗口

1 : 激活指定窗口

2 : 最小化指定窗口,但不激活

3 : 最小化指定窗口,并释放内存,但同时也会激活窗口.(释放内存可以考虑用[FreeProcessMemory](../内存/FreeProcessMemory.htm)函数)

4 : 最大化指定窗口,同时激活窗口.

5 : 恢复指定窗口 ,但不激活

6 : 隐藏指定窗口

7 : 显示指定窗口

8 : 置顶指定窗口

9 : 取消置顶指定窗口

10 : 禁止指定窗口

11 : 取消禁止指定窗口

12 : 恢复并激活指定窗口

13 : 强制结束窗口所在进程.

14 : 闪烁指定的窗口

15 : 使指定的窗口获取输入焦点

返回值:

整形数:  
0: 失败  
1: 成功

示例:

dm\_ret = dm.SetWindowState(hwnd,0)
