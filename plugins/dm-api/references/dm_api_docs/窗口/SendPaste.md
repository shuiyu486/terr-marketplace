# SendPaste

**分类:** 窗口

**签名:** `long SendPaste(hwnd)`

**描述:** 向指定窗口发送粘贴命令. 把剪贴板的内容发送到目标窗口.

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| hwnd | int | 指定的窗口句柄. 如果为0,则对当前激活的窗口发送. |

## 返回值

- 0: 失败
- 1: 成功

## 示例

```vbs
dm.SetClipboard "abcd"
dm.SendPaste hwnd
```

## 注意

- 剪贴板是公共资源，多个线程同时设置剪贴板时,会产生冲突，必须用互斥信号保护.
